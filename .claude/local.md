# Local Preferences

## Commit Messages

- Use Conventional Commits format for the subject line: `<type>: <short summary>`
  (types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `chore`).
- Follow the subject with exactly one blank line, then a single-line
  description of what changed and why. No multi-paragraph bodies.
- Never add a `Co-Authored-By: Claude` trailer or any Claude/session link to
  commit messages.
